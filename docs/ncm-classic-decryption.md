# CLASSIC_NCM 解密流程

## 识别文件

首先读取文件开头 10 字节。

前 8 字节必须是 ASCII 文本 `CTENFDAM`。后 2 字节在当前样本中为十六进制 `01 70`，应当记录为格式特征，但不能只依靠这两个字节判定版本。

文件可按以下结果分类：

```text
固定标识不匹配                         -> NOT_NCM
长度字段越界或文件提前结束             -> DAMAGED
经典密钥和元数据可解，音频头也合法     -> CLASSIC_NCM
固定标识匹配，但经典密钥无法解开       -> UNSUPPORTED_VARIANT
```

## 解出音频流密钥

1. 按小端序读取 4 字节密钥区长度。
2. 读取完整密钥区，并检查长度没有超过文件剩余范围。
3. 将密钥区每个字节与 `0x64` 异或。
4. 使用 AES-128-ECB 和 PKCS5/PKCS7 填充方式解密。
5. 验证明文以 `neteasecloudmusic` 开头。
6. 移除该 17 字节前缀，剩余内容就是音频流密钥。

AES 固定密钥为：

```text
hzHRAmso5kInbaxW
```

如果 AES 解密失败、填充无效或前缀不匹配，应将文件视为不支持的变体，而不是继续猜测偏移量。

## 解出元数据

1. 按小端序读取 4 字节元数据区长度。
2. 读取完整元数据区，并检查长度边界。
3. 将每个字节与 `0x63` 异或。
4. 验证并移除 `163 key(Don't modify):` 前缀。
5. 对剩余内容执行 Base64 解码。
6. 使用元数据固定密钥执行 AES-128-ECB 和 PKCS5/PKCS7 填充解密。
7. 验证明文以 `music:` 开头。
8. 移除该前缀，把剩余 UTF-8 内容作为 JSON 元数据。

元数据 AES 固定密钥为：

```text
#14ljk_!\]&0U<'(
```

当前样本的 JSON 包含歌曲名、歌手、专辑、码率、时长和格式等信息，但没有歌词字段。

## 读取封面

元数据区之后依次跳过 4 字节 CRC 和 5 字节保留区域，再按小端序读取 4 字节封面长度。

随后读取指定长度的原始图片数据。可以通过文件头判断图片类型：

```text
FF D8 FF                         -> JPEG
89 50 4E 47 0D 0A 1A 0A         -> PNG
```

该图片可以作为 MP3 的 ID3v2 `APIC` 帧写入，也可以作为 FLAC 的 PICTURE 元数据块写入。

## 解密音频

根据音频流密钥初始化 S-box：

```text
S[i] = i
j = (j + S[i] + key[i % keyLength]) % 256
交换 S[i] 和 S[j]
```

从封面区结束后的第一个字节开始，把音频绝对位置记为 `p = 0`。对每个密文字节计算：

```text
i = (p + 1) % 256
j = (S[i] + i) % 256
K = S[(S[i] + S[j]) % 256]
明文[p] = 密文[p] XOR K
```

实现流式读取时必须保留绝对位置 `p`，不能让每个缓冲区随意从 0 重新计数。旧项目使用 `0x8000` 字节缓冲区，而 `0x8000` 恰好是 256 的整数倍，所以重置计数仍能得到正确结果；新版不应依赖这个隐含条件。

## 判断输出格式

优先根据解密后的音频头判断真实格式，不只相信 JSON 中的扩展名：

```text
49 44 33                         -> 带 ID3 标签的 MP3
FF FB、FF F3 或 FF F2            -> 可能是不带 ID3 标签的 MP3
66 4C 61 43                      -> FLAC
```

确认格式后，再选择 `.mp3` 或 `.flac` 输出扩展名。

## 整合元数据、封面和歌词

对于 MP3，可以把 NCM JSON 中的歌曲名、歌手和专辑写入 ID3v2 标签，并把封面写入 `APIC` 帧。

当前样本没有内置歌词，因此不能仅凭 NCM 文件生成歌词。若另有 LRC 文件，可以选择保留同名 `.lrc` 文件，或者把纯歌词文本写入 ID3v2 `USLT` 帧。带时间轴的逐行歌词更适合继续保留为独立 LRC，因为播放器对 ID3v2 `SYLT` 同步歌词的支持并不一致。

首版转换器可以先原样输出已解密音频，不修改标签。确认核心解密稳定后，再增加元数据和封面写入，便于区分解密失败和标签回写失败。
